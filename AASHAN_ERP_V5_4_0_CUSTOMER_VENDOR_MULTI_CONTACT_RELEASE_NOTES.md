# Aashan ERP v5.4.0 - Customer & Vendor Multiple Contacts

## Added
- Customer master now accepts multiple phone numbers.
- Customer master now accepts multiple email addresses.
- Vendor master now accepts multiple phone numbers.
- Vendor master now accepts multiple email addresses.
- Multi-contact fields support new lines, commas, or semicolons.
- Customer/Vendor list displays each phone/email on separate lines.
- Email sending now accepts multiple recipients from a multi-email field.
- Mobile call/text actions use the first available phone number.

## SQL
Run:

`supabase/aashan_erp_v5_4_0_customer_vendor_multi_contact.sql`

This keeps the same database columns and only confirms they are text fields.
