# Aashan ERP v4.0.1 — Aashan AI Actions

## Added
- Aashan AI can now create a draft quote directly from a typed request.
- Added AI response copy button.
- AI quote builder extracts customer name when possible.
- AI quote builder creates multiple quote lines from comma, semicolon, newline, plus sign, or "and" separated scope text.
- Draft quote opens directly in the existing Quotes screen for review before saving.

## Notes
- No database migration required.
- Existing transaction, attachment, email, tax, and report logic was not changed.
