# Aashan ERP v5.2.0 Command Palette Release Notes

## Added
- Global Command Palette available from desktop and mobile.
- Keyboard shortcut: Ctrl+K / Cmd+K.
- Slash shortcut `/` opens the command palette when not typing in a field.
- Quick commands for Dashboard, Quote, Invoice, Customer, Work Order, Receipt, Reports, Accounting, and Aashan AI.
- Enter key runs the first matching command.
- Mobile-friendly overlay with large touch targets.

## Verified
- `npm install`
- `npm run build`

## SQL
- No SQL migration required.
