# Aashan ERP v3.4.2 Dashboard Drilldown Fix

## Scope
This release only adds dashboard drilldown navigation for mobile and browser. No attachment, tax, email, posting, or database logic was changed.

## Added
- Balance Sheet dashboard cards are now tappable/clickable.
- Assets opens Balance Sheet.
- Accounts Receivable opens Customer Statement.
- Cash & Bank, Bank, and Cash on hand open Bank Register.
- Liabilities opens Balance Sheet.
- Accounts Payable opens Vendor Statement.
- Tax Payable opens General Ledger.
- Equity opens Balance Sheet.
- Current Year Profit opens Profit & Loss.
- Profit & Loss dashboard rows open Profit & Loss.

## Validation
- npm install completed.
- npm run build completed successfully.
