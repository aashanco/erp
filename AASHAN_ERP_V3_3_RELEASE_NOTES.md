# Aashan ERP v3.3 – Scheduling + Technician App

## New
- Scheduling calendar foundation for work orders.
- Technician mobile dashboard for today’s jobs.
- Work order priority, customer phone, customer address, completion notes, start/completion timestamps.
- Quick technician actions: Call, Text, Navigate, Start Job, Complete Job.
- Convert completed work order to invoice draft.
- Additive database tables for technicians, schedule, and status history.

## Not Changed
- Accounting engine.
- General Ledger.
- Dashboard calculations.
- Reports.
- Customer invoice/receipt posting logic.
- Purchase invoice/vendor payment posting logic.

## SQL
Run `supabase/aashan_erp_v3_3_scheduling_technician.sql` first.
